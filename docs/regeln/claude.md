# Claude

Harte Regel aus `CLAUDE.md` („Harte Regeln“), hierher ausgelagert, damit `CLAUDE.md` unter 80 KB bleibt. Sie gilt unverändert und vollständig; `CLAUDE.md` nennt nur die Kurzfassung.

- **Claude (vom Nutzer freigegeben – „Lokal + Claude optional“; Häkchen `claude_on` Suche, `claude_editor` Clip-Editor, `claude_image` Bild-Editor, `claude_frame` Standbilder, `claude_stats` Statistik – alle Standard aus; Bilder mit Hinweis „können Spielernamen zeigen“):** die Suche (Befehlspalette, Strg+F) arbeitet immer lokal; nur wenn der Nutzer die Zeile „Claude fragen“ wählt (Enter/Klick, **nie je Tastendruck**), schickt `askclaude.py` (nur Standardbibliothek) **eine** Anfrage an `ENDPOINT` = `https://api.anthropic.com/v1/messages` (Modell aus `MODELS` per `claude_model`/`set_model`, `effort` low, strukturierte Ausgabe `SCHEMA`; Fallback-Parameter nur bei `FALLBACK_MODELS`). Gesendet werden **nur** die Frage (≤ `MAX_QUESTION` Zeichen) und der Katalog der programmeigenen Einträge Einstellungen/Seiten/Aktionen als „id⇥Titel“ (`app_palette.CLAUDE_KINDS`, ≤ `MAX_CATALOGUE`) – **nur feste Programmtexte** (`app_palette.claude_catalogue`: Text wörtlich in i18n = `i18n.is_program_text`; ids opak), **nie** Statuszeilen, Fehlermeldungen, Runden, Maps, Killer, Pfade, Server, Pings, Spieldaten. Claudes Texte nur als Klartext (`qt_common.PlainLabel`). Die Antwort wird nur als ids aus genau diesem Katalog genutzt (`askclaude.parse`, ≤ `MAX_IDS`), ausgeführt wird erst, was der Nutzer wählt. Eigener API-Key des Nutzers per DPAPI (`spotify.protect` für alle `SECRET_KEYS`: nie `plain:` schreiben, ohne DPAPI `spotify.CannotProtect` → Wert nur für die Sitzung) in `claude_key` (`SECRET_KEYS` + `LOCAL_KEYS`, nie Export); Key und Frage nie ins Log/die Diagnose (`_claude_diag` = nur Zähler). „Key prüfen“ = eine Mini-Anfrage auf Klick. Kosten nur geschätzt aus `usage` × `PRICES` (`METER`, Monatssumme `claude_spent`, nur Zahlen); der feste Teil einer Anfrage (Katalog, Zusammenfassung) als `askclaude.cached`-Block. Nie in Erkennung/Overlay. **Clip-Editor (`editorclaude.py`):** nur auf „Vorschlagen“/Enter eine Anfrage über `askclaude.request`; gesendet werden **nur** die Bitte des Nutzers (≤ `editcommands.MAX_REQUEST`) und `editcommands.describe` = der Schnitt als Zahlen (Länge, Clips in Ausgabezeit, Tempo, Standbild ja/nein, Blenden, Export-Art, eigener Short-Titel/Untertitel, F8-Marken) – **nie** Pfade, Dateinamen, Map, Killer; die Antwort gilt nur als Operationen aus `editcommands.KINDS`, geprüft von `editcommands.apply`, ausgeführt erst auf „Übernehmen“ (ein Undo-Schritt); Rückfragen ≤ `MAX_ROUNDS`, Verlauf nur im Speicher. **Bilder:** Bild-Editor (`claude_image`, `imageclaude.py`) und Clip-Editor (`claude_frame`, Häkchen „Standbild mitsenden“ je Bitte, „Highlights finden“ mit `highlights.still_times` ≤ `STILL_SIDE` + Länge + F8-Marken) schicken **nur auf Klick** Bilder über `askclaude.image_block` (JPEG nur im Speicher, längste Seite ≤ `IMAGE_SIDE`, nie eine Datei, nie Pfad/Dateiname) – immer mit den bereits zensierten Bereichen zensiert (`imageclaude.picture`, `editorclaude._claude_still_job`); die Antwort gilt nur als Operationen aus `imageclaude.KINDS` bzw. `editcommands.KINDS` (`censor` nur mit Standbild) bzw. Bereiche aus `highlights.parse` → `keep`, ausgeführt erst auf „Übernehmen“; `claude_short` (nur mit `claude_frame`): Standbilder an `moments`-Spitzen + `moments.facts` (nur Zahlen); `claude_text_names`: Standbild mit nummerierten Kästen, Antwort nur Nummern; `claude_check`/`claude_thumb`: 8 Standbilder des Schnitts, Antwort nur `check_parse`/`thumb_parse` (Bild nur Datei). **Statistik:** die Palette-Zeile „Claude zur Statistik fragen“ und die festen Einträge „Claude: Woche zusammenfassen“/„Welcher Build läuft am besten?“ senden nur die Frage und `statsclaude.summary` bzw. `week` = Zähler/Mittel/Quoten je Gruppe (Rolle, eigener Killer, Map, gegnerischer Killer als Charakter, Region, Tageszeit, Wochentag, **eigene** Perks aus den offiziellen Daten; Gruppen < `MIN_GROUP` weg) – **nie** eine einzelne Runde, Uhrzeiten, Spielernamen, Gegner-Loadouts, Pfade, Server-IPs, Songtitel; Antwort nur Klartext.
